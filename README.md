# 앱홍보글 에이전트

앱 소개와 업데이트 내역을 넣으면 스토어 설명문 · 인스타 글 · 업데이트 공지 초안을 써 주는 Claude용 에이전트 폴더입니다.

## 준비물
- Claude 데스크톱 앱(Cowork) 또는 Claude Code — 폴더를 연결해 쓸 수 있는 것
- 이 보관함을 내려받은 폴더 (초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기)

쓰는 방법은 두 가지입니다. 처음이라면 (가)를 추천합니다.

- **(가) 폴더로 쓰기** — 내려받은 폴더를 Claude에 연결해 그 안에서 씁니다. 아래 「넣을 자료」부터 따라 하면 됩니다.
- **(나) 스킬로 설치해 쓰기** — 한 번 설치해 두면 어느 폴더에서든 불러 씁니다. 맨 아래 「스킬로 설치하기」를 봅니다.

## 넣을 자료
`자료/` 폴더의 파일 3개를 내 앱 내용으로 바꿔 씁니다.

| 파일 | 적을 것 |
|---|---|
| `앱소개.md` | 앱이 하는 일 · 쓰는 사람 · 기능 · 가격 · 스토어 |
| `업데이트내역.md` | 버전별로 바뀐 것 (맨 위가 가장 최근) |
| `말투.md` | 글의 말투 · 꼭 쓰는 표현 · 쓰면 안 되는 표현 |

처음에는 들어 있는 가상 앱 「걸음모아」 자료로 먼저 돌려 보세요.
내려받은 폴더는 내 컴퓨터에만 있으므로, 바꿔 넣은 자료가 이 보관함으로 올라가지는 않습니다.

## 시키는 말 한 줄
폴더를 Claude에 연결하고 아래처럼 보냅니다.

```
CLAUDE.md의 흐름을 1단계부터 3단계까지 해줘.
```

글을 다 쓰면 한 번 멈추고 묻습니다. 초안을 보고 `응, 3단계로 가줘` 라고 답하면 확인표까지 만듭니다.

## 결과가 쌓이는 곳
`결과/` 폴더에 날짜가 붙은 파일로 저장됩니다.

| 파일 | 내용 |
|---|---|
| `홍보재료_날짜.md` | 자료에서 뽑은 글 재료 |
| `스토어설명문_날짜.md` | App Store 부제 · 프로모션 텍스트 · 설명문 · 키워드, Google Play 간단한 설명 |
| `인스타글_날짜.md` | 각도가 다른 글 3안과 해시태그 |
| `업데이트공지_날짜.md` | 스토어 「새로운 기능」 문구와 앱 안 공지문 |
| `게시전_확인표_날짜.md` | 글자 수 한도, 숫자 · 가격 대조, 게시 전에 확인할 곳 |

한 일은 `작업일지.md` 에 한 줄씩 쌓입니다.

## 알아 둘 것
- 초안까지만 만듭니다. 스토어 등록과 게시는 직접 합니다.
- 자료에 없는 내려받은 수 · 별점 · 순위 · 후기는 쓰지 않도록 되어 있습니다. 모르는 것은 「확인 필요」로 남습니다.
- 글자 수 한도는 스토어 정책이 바뀌면 달라질 수 있습니다. 등록하기 전에 스토어 화면에서 한 번 확인하세요.
- 들어 있는 「걸음모아」는 교육용 가상 앱입니다. 실제로 있는 앱이 아닙니다.

## 스킬로 설치하기
`skill/app-promo-writer/` 폴더가 스킬입니다. 안에 `SKILL.md` 하나가 들어 있습니다.

- **Claude Code** — `app-promo-writer` 폴더를 통째로 `~/.claude/skills/` 안에 복사합니다. 새로 연 세션부터 쓸 수 있습니다.
- **Claude 데스크톱 앱 · claude.ai** — `app-promo-writer` 폴더를 zip으로 압축해 설정의 스킬(Skills) 화면에서 올립니다. 메뉴 이름과 위치는 버전에 따라 다를 수 있습니다.

설치한 뒤에는 내 앱 자료가 있는 폴더에서 이렇게 말합니다.

```
앱 홍보글 써줘
```

폴더에 `자료/` 가 없으면 스킬이 앱에 대해 하나씩 물어 자료 파일부터 만듭니다. 「업데이트 공지만 써줘」처럼 일부만 부탁해도 됩니다.

## 폴더 구성
```
CLAUDE.md     에이전트가 읽는 일 설명서 — (가) 폴더로 쓸 때
skill/        설치해서 쓰는 스킬 — (나) 스킬로 쓸 때
자료/         내 앱 자료 3개 (가상 앱 예제가 들어 있음)
결과/         만든 글이 쌓이는 곳
작업일지.md   한 일 기록
```
